# Writing for people: the core

**This skill is a core, not a task.** Its rules are in `core.md` beside this file, and every child skill reads that file before its own rules. Typed on its own, it only shows the core: read `core.md`, then wear the child that fits what is being written.

**Changing the core changes every child.** The children are `write-to-a-person`, `write-for-the-reader`, `write-the-docs`, `write-an-incident-update` and `record-the-why`.
